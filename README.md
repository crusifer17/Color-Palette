# Color Palette Explorer

A lightweight React 19 application that displays all 16,777,216 colors from #000000 to #ffffff in an interactive grid.

## Features

- 🎨 Complete color spectrum from #000000 to #ffffff
- 📋 One-click copy to clipboard for hex codes
- 🔄 Toggle between paginated and continuous scroll modes
- ⚡ Lazy loading for optimal performance
- 📱 Responsive design
- 🎯 25x4 grid layout (100 colors per page in paginated mode)

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Usage

- Toggle pagination ON to browse colors page by page (100 colors per page)
- Toggle pagination OFF to scroll through all colors with lazy loading
- Hover over the copy icon to see it darken
- Click the copy icon to copy the hex code to your clipboard
- Navigate between pages using Previous/Next buttons when pagination is enabled

## Technologies

- React 19
- Vite
- CSS3
